# Учимся читать по-английски

Веб-версия перекидных карточек Word Family Build Book: справа неподвижная
рифма (`-in`), слева перелистываются начала слов — `p`→pin, `b`→bin, `w`→win.
33 группы, 612 слов — по 7–20 в группе, включая редкие: набор задуман как
материал для отбора, лишнее убирается правкой `wordFamilies.ts`.
У слова может не быть картинки (`emoji` необязателен) — тогда карточка
показывает только буквы. Перевод (`ru`) обязателен и показывается под словом.

Книжка работает в обе стороны. Обычная группа держит неподвижным окончание
(`side: 'end'`): `-in` → pin, bin, win. Группа про звук в начале держит
неподвижным начало (`side: 'start'`): `th-` → think, three, thumb — тогда
листается правая половина, а спираль переезжает вправо.
Ребёнок листает, взрослый рядом проговаривает звуки.

## Запуск

```sh
npm install
npm run dev      # http://localhost:5173
```

Сборка статики: `npm run build` → `dist/` (можно просто открыть с любого
статического хостинга или положить на планшет).

Сверху — вкладки: **Чтение** (группы по звукам), **Местоимения**, **Вопросы**.

## Как это устроено

- `src/data/wordFamilies.ts` — всё содержимое. `decks` — вкладки, каждая со
  своими разделами: `familySections` (чтение), `pronounSections`,
  `questionSections`. Слово складывается из неподвижной части группы (`fixed`)
  и переменной части карточки (`part`) — порядок задаёт `side`. Если `fixed`
  пустой, карточка цельная (так сделаны местоимения и вопросы), а подпись на
  плитке берётся из `title`. Поля `example` и `exampleRu` добавляют к карточке
  фразу-пример с отдельной кнопкой озвучки.
- `src/components/FlipBook.tsx` — книжка с переворотом страницы (CSS 3D).
- `src/components/FamilyPicker.tsx` — выбор группы, разложенный по разделам.
- `src/hooks/useProgress.ts` — прогресс в localStorage. На экране он не
  показывается: нужен только чтобы вернуть ребёнка на ту карточку, где он
  остановился. Полностью пройденная группа открывается заново с первой.
- `src/hooks/useSpeech.ts` — озвучка через Web Speech API браузера.

Группа открывается как отдельный адрес (`/#in`), поэтому кнопки «назад» и
«вперёд» в браузере переключают между списком и книжкой, а ссылкой на группу
можно поделиться.

Управление: клик по карточке или `→` — следующее слово, `←` — предыдущее,
пробел — произнести ещё раз, `Esc` — вернуться к группам. Слово произносится
само при входе в группу и при каждом перелистывании. После последнего слова
группы открывается экран поздравления с кнопкой на главную.

## Добавить группу или слово

Дописать в `src/data/wordFamilies.ts`:

```ts
{
  id: 'ump',
  fixed: 'ump',
  side: 'end',
  color: '#2eb872',
  words: [
    { part: 'j', emoji: '🤸', ru: 'прыгать' },
    { part: 'b', emoji: '🤕', ru: 'шишка' },
  ],
}
```

`id` попадает в адрес (`/#ump`) и должен быть уникальным — поэтому у двух
групп `th` он разный (`th-think`, `th-this`), а `hint` подписывает их на
плитке. Группа кладётся внутрь того раздела, чей звук она даёт.

Затем скачать недостающие картинки:

```sh
npm run icons
```

Скрипт берёт эмодзи из данных и кладёт соответствующие SVG из
[OpenMoji](https://openmoji.org) (CC BY-SA 4.0) в `public/icons/`.
Если для эмодзи картинки нет, он напишет, для какого слова её не хватило.
